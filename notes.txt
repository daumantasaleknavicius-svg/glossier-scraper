# Glossier Scraper - Technical Notes

## Tools
- Node.js
- Playwright
- JavaScript
- Visual Studio Code
- Git and GitHub

## Approach
The scraper uses Playwright to collect product data from the Glossier website. Browser rendering was chosen because the product listing contains dynamically loaded content.

The scraper scrolls through the collection page to load products, extracts basic product information using HTML selectors, and visits individual product pages to collect descriptions.

For the stretch tasks, the scraper also retrieves Shopify product data to extract all available variants. Each variant is saved as a separate CSV row with its own ID, name, price, and URL.

The scraper runs separately for the Lithuanian and US storefronts.

## Assumptions and Decisions
- Product IDs are stored as strings to preserve their original representation.
- Shopify variant IDs are used as unique identifiers rather than product IDs.
- Image URLs are stored as arrays of strings, even when only one image is available.
- Image URL query parameters are removed to avoid explicitly resized versions.
- Prices are stored as formatted strings in EUR for Lithuania and USD for the US.
- When Shopify returns a zero variant price, the collection page price is used as a fallback.
- Scraping timestamps are stored as ISO 8601 strings.
- Product descriptions are extracted from product pages, with metadata used as a fallback when available.
- Duplicate variant IDs are removed before saving.
